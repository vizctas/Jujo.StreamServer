## Findings

### 🔴 CRITICAL BUG #1: Duplicate `serverStatusProvider`

**Location:**
- `lib/core/providers/server_status_provider.dart` → `StateNotifierProvider<ServerStatusNotifier, ServerStatus>`
- `lib/core/services/server_status_service.dart` → `StreamProvider.autoDispose<ServerStatus?>`

**Impact:** Split-brain — different screens import different providers. Dashboard may show "online" while Game Sources shows "offline".

**Fix Required:** Consolidate into single provider. Remove the duplicate in `server_status_service.dart` or rename it to avoid collision.

---

### ⚠️ ALERT #2: Missing Display Mode Settings

**Location:** `lib/features/streaming/stream_config_screen.dart`

**Impact:** Users cannot change resolution/FPS/display output from Flutter app. Must use web UI.

**Server supports:** `resolution`, `fps`, `output_name`, `hdr` config keys.

**Fix Required:** Add resolution, FPS, display output, and HDR controls to `_AdvancedMode` widget.

---

### ⚠️ ALERT #3: `http` Package Not in pubspec.yaml

**Location:** `pubspec.yaml` missing explicit `http` dependency.

**Impact:** Works via transitive dep from `supabase_flutter`. Could break on updates.

**Fix Required:** Add `http: ^1.2.0` to pubspec.yaml dependencies.

- No hardcoded secrets
